# Referencias visuales — landing rediseño

## Tono objetivo: SaaS moderno limpio

### Referencias primarias
- **Linear** (linear.app) — tipografía grande, mucho espacio negro/blanco, screenshots grandes de producto, hero claro.
- **Stripe** (stripe.com) — gradientes sutiles, transiciones limpias, heroes con visual a la derecha, grids de features.
- **Cobee** (cobee.io) — competidor directo español; ver cómo encuadran el beneficio social + fiscal.

### Patrones que nos interesan
- Hero con texto a la izquierda + screenshot/visual a la derecha
- Sección de logos de clientes (cuando los tengamos)
- Grid de 3×2 features con icono + título + desc (tipo Linear)
- Comparativa tipo tabla con columnas (Plati vs Cobee vs Edenred)
- Calculadora interactiva embebida (referencia: calculadoras de Stripe para fees)
- FAQ con accordion expandido visualmente claro
- CTA banner azul al final de cada página
- Footer con 4 columnas limpio

### Anti-patrones (evitar)
- Carruseles de testimonios automáticos
- Background videos pesados
- Demasiados gradientes saturados
- Ilustraciones 3D genéricas tipo AI-stock
- Popups de chat intrusivos (chat fuera de v1)
- Hero con 5 CTAs compitiendo
- Logos de clientes inventados o stock
